문의 및 오류 제보

콘텐츠 수치나 출처의 오류, 서비스 이용 중 발견한 문제는 GitHub 저장소의 이슈로 알려주세요. 문제가 발생한 페이지 주소와 재현 방법, 기대한 결과를 함께 적으면 확인에 도움이 됩니다.

GitHub에서 오류·정정 요청 작성하기

GitHub 로그인이 필요하며, 제출하는 이슈는 공개됩니다. 비밀번호, 인증키, 전화번호, 상세 건강 정보 등 개인정보를 적지 마세요. 제출 전 첨부 이미지에서도 개인정보를 가려 주세요.

콘텐츠 정정을 요청할 때

  • 해당 글의 주소와 수정이 필요한 문장 또는 수치를 적어 주세요.
  • 공식 자료나 원문 연구 링크가 있다면 함께 알려주세요.
  • 서비스 오류는 사용 기기·브라우저와 발생 순서를 적어 주세요.

접수와 답변은 GitHub 이슈 화면에서 확인할 수 있습니다. 이 페이지에서 별도로 문의 내용을 수집하거나 전송하지 않습니다.
