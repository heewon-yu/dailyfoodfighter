## Codex 최종 작업 지시
1. 두 저장소 main, 최신 배포 커밋, 기존 Android 코드/CI/앱 자산을 먼저 조사. 이미 구현된 기능은 중복 구현하지 않는다. 운영 웹과 앱의 소스 및 자산 버전 일치, 기존 블로그/단타왕 무영향. 개발 브랜치와 PR 사용.
2. 웹 UI를 Android 앱으로 패키징(기존 구조 우선, 없으면 Capacitor 검토). 오프라인 로컬 자산 번들, Noto Serif KR 서체 일관성 및 라이선스 확인, 세로모드/안전영역/뒤로가기/상태복원/접근성/저사양 대응. API는 절대 HTTPS 운영 주소 사용. 네트워크 오류 시 게임 자체는 유지하고 랭킹 재시도/오류 표시. 원격 페이지 로그인/광고 의존으로 게임이 멈추지 않도록 한다.
3. Android에서 AdMob 보상형 광고는 단서 기능 활성화에만 사용. 사건당 1회, 전체 최대 3회 동일 유지. 사용자 버튼 표기는 기존 '단서 보기', 광고 시청 후 공개라는 추가 문구 제거. 사용자 선택 시 광고 시작 전 타이머 및 입력 정지, 광고 재생/종료 동안 시간 소모 없음. 보상 콜백 성공 시에만 단서 1회 차감 및 공개, 중복 콜백 방지. 실패/취소/미충족은 차감/공개하지 않고 재개. 앱 백그라운드 악용 방지, 광고 중 타이머 정지와 일반 백그라운드 구분. 웹은 광고 없이 기존 기능 유지. 테스트 광고 ID와 실광고 ID 분리, 정책상 필수 동의/고지 및 적절한 광고 UX 적용. 실제 SDK/정책 최신 문서 확인.
4. Cloudflare D1 Pages Functions 기존 API 재사용, KST 일일 TOP5, 닉네임당 당일 최고점, 개인 최고기록. 서버 검증 score=solved*100, 0~10000, solved 0~100, hints 0~3. 현재 클라이언트 제출값 신뢰 한계 존재: 출시 전 서버 세션/재전송 방지 및 부정행위 방어 검토·구현, 기존 기록 호환 및 데이터 최소화. 계정/저장 규칙 임의 변경 금지.
5. 테스트: 100문항 ID/제목/정답/선택지/단서/이미지 경로 검증; 이미지 디코딩/해시/시각적 유사성; 독립 풀이/모호성/권리 검토; 300초/100점/단서 상한/광고 성공·실패·취소/중복 콜백/시간 정지·재개; TOP5·KST 자정·동점·오프라인·악성 제출/개인기록; 320/360/390/412px 및 실기기/태블릿, 글꼴·두 줄 안내, OG URL 검증. 실제 실행한 결과 및 실패 로그 기록.
