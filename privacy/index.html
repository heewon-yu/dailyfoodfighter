개인정보처리방침

데일리푸드파이터(이하 '사이트')는 생활 도구, 게임 및 영양 콘텐츠를 제공합니다. 본 방침은 이용자가 블로그를 방문하고 이용하는 과정에서 수집되는 정보와 그 이용 목적, 보호 조치에 대해 설명합니다.

1. 수집하는 정보 및 수집 방법

블로그는 회원가입이나 로그인을 요구하지 않으며, 이용자의 주민등록번호나 민감한 개인정보를 직접 수집하지 않습니다. 다만, 서비스 이용 과정에서 아래와 같은 정보가 자동으로 생성되거나 제3자 서비스를 통해 수집될 수 있습니다.

  • 방문 일시, IP 주소, 브라우저 종류, 운영체제, 페이지 뷰 수 등 통계적 로그 데이터
  • 공개 GitHub 오류 제보에 이용자가 직접 작성한 내용과 GitHub 프로필 정보. 해당 정보는 GitHub의 정책과 공개 범위에 따라 처리됩니다.

2. 쿠키(Cookie) 및 웹 비콘의 사용

블로그는 방문자에게 보다 나은 서비스를 제공하고 맞춤형 광고를 제공하기 위해 '쿠키(Cookie)'를 사용할 수 있습니다. 쿠키는 웹사이트를 방문할 때 웹 브라우저를 통해 방문자의 컴퓨터 또는 모바일 기기에 저장되는 작은 텍스트 파일입니다.

  • 쿠키 설정 거부 방법: 이용자는 웹 브라우저의 옵션을 조정하여 모든 쿠키를 허용하거나, 쿠키가 저장될 때마다 확인을 거치거나, 모든 쿠키의 저장을 거부할 수 있습니다. 단, 쿠키 저장을 거부할 경우 웹사이트 일부 기능 이용에 어려움이 있을 수 있습니다.

3. 제3자 광고 프로그램 (Google AdSense) 관련 고지

사이트 공통 레이아웃에는 Google AdSense 스크립트가 포함되어 있습니다. 스크립트 포함 여부는 광고 승인이나 실제 광고 게재를 의미하지 않습니다. 광고 제공 시 Google 및 파트너가 정보를 처리할 수 있습니다.

  • Google 및 제3자 벤더는 쿠키를 사용하여 이용자가 본 블로그 또는 다른 웹사이트를 방문한 기록을 바탕으로 관련성 높은 광고를 게재합니다.
  • Google의 광고 쿠키 사용으로 인해 Google 및 파트너사는 이용자의 본 사이트 및 인터넷 상의 다른 사이트 방문 정보를 기반으로 광고를 제공할 수 있습니다.
  • 이용자는 Google 광고 설정을 방문하여 맞춤형 광고 게재를 비활성화할 수 있습니다.

방문 분석과 외부 서비스

사이트 공통 레이아웃은 Google Analytics 4를 사용해 페이지 이용과 방문 통계를 측정합니다. Google 서비스가 포함된 페이지를 방문하면 페이지 URL, IP 주소, 브라우저 정보와 쿠키·식별자 등이 Google로 전송되거나 처리될 수 있습니다. 광고 사업자는 브라우저에 쿠키를 저장·읽거나 웹 비콘과 IP 주소 등을 이용할 수 있습니다. 적용 범위는 방문한 서비스와 제공자의 설정에 따라 달라집니다.

Google 파트너 사이트 정보 이용 안내 · Google 개인정보처리방침 · Google 광고 설정 · Google Analytics 차단 브라우저 부가 기능

사이트 제공에는 Cloudflare Pages·Workers가 사용됩니다. 연결 요청과 보안 로그 등은 인프라 제공자의 처리 대상이 될 수 있습니다. Cloudflare 개인정보 안내를 확인하세요. 게임 랭킹 등 일부 기능은 서버에 기록을 보내며, 브라우저 저장 기능과 별개로 처리됩니다. 혜택찾기 프로필 처리 안내는 혜택찾기 안내 페이지에서 확인할 수 있습니다.

4. 개인정보의 보유 및 파기

공개 GitHub 이슈는 해당 저장소와 GitHub 정책에 따라 보관됩니다. 공개 제보에 개인정보를 기재하지 마세요. 브라우저에 저장되는 설정과 기록은 해당 서비스의 삭제 기능 또는 브라우저 사이트 데이터 삭제로 제거할 수 있습니다. 제3자 서비스의 보관 기준은 아래 제공자 정책을 확인하세요.

  • 운영자/관리자: 데일리푸드파이터 운영팀
  • 문의 접수처: 데일리푸드파이터 온라인 문의 페이지
