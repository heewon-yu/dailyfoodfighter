# 한입.한밤.해외지도 (`/map/`) — 영상 속 맛집·숙소·해외 호텔 찾기

유튜브에 소개된 국내 맛집과 숙소를 지도에서 찾고 원본 영상을 확인할 수 있는 페이지입니다.
상단에서 **한입지도**·**한밤지도**·**해외지도**를 전환할 수 있습니다. 세 화면은 `/map/` 주소를 공유합니다.
외부 프레임워크 없이 동작하며, `main` 브랜치에 푸시하면 Cloudflare Pages가 자동 배포합니다.

---

## 1. 서비스 개요와 이전 경위

- **초기**: ChatGPT Sites로 만든 별도 사이트 `map.dailyfoodfighter.com`에서 운영.
- **현재**: 이 저장소의 `/map/` 경로(`https://dailyfoodfighter.com/map/`)로 이전 완료.
  - 블로그·혜택찾기·게임과 같은 도메인에서 관리되므로 검색 노출과 운영이 한곳으로 모입니다.
  - 옛 주소 `map.dailyfoodfighter.com`은 **301 리다이렉트**로 새 주소에 연결합니다.
    (리다이렉트는 Cloudflare 대시보드의 Redirect Rules에서 관리하며, 이 저장소에는 설정 파일이 없습니다.)
- **한입지도**: 구독자 10만 명 이상 채널이 실제로 방문·소개한 국내 식당을 수록합니다.
- **한밤지도**: 선정한 채널의 원본 영상이 객실이나 숙박 경험을 직접 소개하는지 확인하고, 정확한 지점명과 주소를 대조합니다. 게스트하우스로 운영되는 숙소는 수록 대상에서 제외합니다. 구독자 10만 명 이상 채널과 별도로 지정한 숙소 리뷰 채널을 포함합니다. 여러 장소를 다룬 영상은 확인 가능한 숙소 구간에 연결합니다. 한 숙소에 여러 원본 리뷰가 있으면 `reviews`에 추가하면 됩니다. 채널을 선택하면 해당 채널의 리뷰가 카드에 표시됩니다.
- **숙소 영상 확인 범위**: 채널별 공개 일반 영상, 쇼츠, 다시보기 목록을 확보한 뒤 영상별로 확인합니다. 같은 영상에 여러 숙소가 나오면 숙소별 주소와 확인 가능한 등장 시점을 기록합니다. 목록을 수집한 단계와 영상 전체를 확인한 단계는 구분합니다.
- **공식 5성급 숙소 점검 (2026-11-22)**: 호텔업 등급결정사업 명단의 제주 외 74곳과 제주특별자치도관광협회 11월 3일 공표 명단의 유효 등급 18곳을 대조했습니다. 누락된 38곳을 추가했고, 정확한 지점과 객실이 확인되면 구독자 10만 명 미만 채널의 원본도 사용했습니다.

## 3. 공유 제목과 미리보기 이미지

`<head>`에 다음 메타가 들어 있습니다. **수정 시 아래 태그를 지우거나 순서를 바꾸지 마세요.**

- `og:type=website`, `og:locale=ko_KR`, `og:site_name=한입.한밤지도`
- `og:url=https://dailyfoodfighter.com/map/`
- `og:title=한입.한밤지도`, `og:description`에 국내 맛집과 숙소를 함께 안내
- `og:image`, `og:image:secure_url` = `https://dailyfoodfighter.com/map/og-hanip-hanbam-illustrated.jpg`
- `og:image:type=image/jpeg`, `og:image:width=1200`, `og:image:height=630`, `og:image:alt`
- `twitter:card=summary_large_image`, `twitter:title`, `twitter:description`, `twitter:image`

대표이미지는 **1200×630 JPEG**(가로:세로 ≈ 1.91:1)로 유지합니다. 이미지 파일명이 바뀌면 `og:image`, `og:image:secure_url`, `twitter:image` 주소를 함께 갱신합니다.

## 4. 데이터 구조

### 4-1. `subscribers` — 채널과 구독자 수

```js
const subscribers = {
  "쯔양": 13500000,
  "성시경 · 먹을텐데": 2360000,
  // … 총 190개 채널
};
```

- **키** = 화면에 표시하는 채널 이름(카드의 `source`·드롭다운 라벨과 같은 문자열).
- **값** = 확인 당시 공개된 구독자 수. 기본은 10만 미만 채널을 수록하지 않지만, **미슐랭 등재 식당(`listings` 9번째 값이 있는 행)은 채널 규모와 관계없이 수록**합니다(가이드가 이미 검증한 식당이라 리뷰 채널의 규모를 기준으로 삼지 않음).
- 채널 드롭다운은 이 객체를 **구독자 수 내림차순**으로 그립니다(영상이 중복 정리된 채널도 목록에는 남습니다).

### 4-2. `listings` — 식당 목록 (9컬럼 배열)

```js
["영선네 국수", "경기", "경기 의정부시 태평로73번길 20", "면요리", "비빔국수", "63yWfN4M-kw", "푸디랜드 FoodieLand", null]
["밍글스", "서울", "서울 강남구 도산대로 67길 19", "한식", "런치·디너 코스", "1zx7ndUJEMc", "입질의추억TV jiminTV", null, "미슐랭 3스타"]
```

| # | 필드 | 설명 |
| --- | --- | --- |
| 0 | `name` | 가게 이름 |
| 1 | `region` | 시·도 **짧은 이름** (`서울`,`부산`,`경기`,`충남`,`세종` … 총 17종). 필터가 이 값으로 동작 |
| 2 | `area` | 상세 주소 또는 동네/랜드마크 표기 |
| 3 | `kind` | 음식 종류 (`국밥`,`면요리`,`중식`,`일식`,`양식`,`분식`,`고기`,`해산물`,`베이커리`,`카페`,`한식`) |
| 4 | `menu` | 대표 메뉴 |
| 5 | `youtubeId` | 유튜브 영상 ID **11자리** |
| 6 | `channel` | `subscribers`에 있는 채널 이름과 **정확히 일치**해야 함 |
| 7 | `start` | 영상 시작 초(정수) 또는 `null`. 값이 있으면 카드에 "1:40부터" 배지와 `t=` 링크가 붙음 |
| 8 | `grade` | (선택) 미슐랭 등급: `미슐랭 3스타`, `미슐랭 2스타`, `미슐랭 1스타`, `빕구르망`, `미슐랭 선정`. 있으면 카드 메타·상세 모달에 등급이 표시되고 검색어("미슐랭", "1스타")로 찾을 수 있습니다 |

### 4-3. 중복 식당 → 대표 유튜버 1개만 표시

같은 가게가 여러 채널 영상에 나오면 **구독자 수가 가장 많은 채널 1개만** 남깁니다. 두 단계로 보장합니다.

1. **데이터 단계**: `listings`를 만들 때 `정규화(가게명) + region`이 같으면 구독자 수가 큰 쪽만 남김.
2. **렌더 단계**: `representativePlaces()`가 실행 시점에 같은 키로 그룹화하고, 구독자 수가 큰 항목을 대표로 선택(동률이면 `start`가 있는 쪽).
   → 나중에 `listings`에 중복을 추가해도 화면에는 항상 1곳만 나옵니다.

```js
const key = [name, region].map(v => v.normalize('NFKC').toLowerCase().replace(/\s+/g,'')).join('|');
```

### 4-3-1. `stays.js` — 한밤지도(국내 숙소)

```js
window.hanbamCatalogue = {
  channels: { "또 떠나는 남자": 783000, "호텔사장 기먼성": 114000, /* … 총 89개 채널 */ },
  stays: [
    {
      name:'레스케이프 호텔', region:'서울', area:'서울 중구 퇴계로 67', kind:'호텔',
      review:'… [레스케이프 호텔] 리뷰', channel:'조승연의 탐구생활', id:'p8RaalqeVkE', start:null,
      official:'https://all.accor.com/korea/index.ko.shtml',
      reviews: [ {review:'레스케이프 호텔 코너 스위트 리뷰', channel:'왓츠인마이트립', id:'K9QSIpXoAKc', start:null} ]
    }
  ]
};
```

| 필드 | 설명 |
| --- | --- |
| `region` | `서울`,`부산`,`제주`,`경기`,`인천`,`강원`,`경북`,`경남`,`세종` 등 17개 시·도 짧은 이름 |
| `area` | 국내 **도로명 주소**(숙소 본관 기준) |
| `kind` | `호텔` / `리조트` / `레지던스` / `독채·풀빌라` / `글램핑·카라반` / `한옥·고택` / `공공 숙소` |
| `review`·`channel`·`id`·`start` | 카드에 표시하는 대표 원본 리뷰 |
| `official` | 숙소·브랜드 공식 페이지 |
| `reviews` | 같은 숙소를 다룬 다른 채널 리뷰. 카드에는 대표 1건만, 상세 모달에서 `채널명 리뷰` 링크로 함께 열립니다 |

- **국내 5대 체인·하이엔드 보강 (2026-11-22)**: 메리어트·힐튼·하얏트·IHG·아코르 계열과 하이엔드·독립 호텔을 대상으로 유튜브 검색(`호텔 리뷰`·`숙박 후기`·`조식`)을 돌려 **원본 34건을 기존 숙소 `reviews`에 추가**하고(레스케이프는 기존 '레스케이프 서울 명동' 카드에 결합), 기존에 없던 **12곳(목시 인사동·코트야드 남대문/세종/판교·힐튼 부산/남해·인터컨티넨탈 코엑스·노보텔 수원·머큐어 홍대/제주·아난티 남해·소노펠리체 비발디파크)을 신규 카드로 추가**했습니다(숙소 230 → 242곳, 영상 287 → 356건, 채널 45 → 89개). 영상은 전부 oEmbed로 공개 상태·제목·채널명을 확인했고, 주소는 카카오·구글 지도에서 해당 주소의 장소가 검색되는지 대조했습니다.
- 제외: 영업을 종료한 하얏트 리젠시 제주(현 더 쇼어 호텔), 확인되지 않은 안다즈 서울 마곡, 주소·영업이 확인되지 않은 노보텔 앰배서더 부산.

### 4-4. `abroads.js` — 해외지도(호텔 + 미쉐린 레스토랑)

```js
window.abroadCatalogue = {
  channels: { "또 떠나는 남자": 783000, "비밀이야 bimirya": 616000, /* … */ },
  places: [
    {
      name:'불가리 도쿄', category:'hotel', region:'일본', area:'일본 도쿄', kind:'메리어트',
      review:'1박 200만 원대 호텔 리뷰', channel:'또 떠나는 남자', id:'YE5AC_04xO0', start:null,
      official:'https://www.bulgarihotels.com/',
      reviews: []   // 같은 호텔의 다른 채널 리뷰
    },
    {
      name:'세잔 SEZANNE', category:'michelin', region:'일본', area:'일본 도쿄', kind:'양식·파인다이닝',
      grade:'미슐랭 3스타', review:'아시아 1등 레스토랑! (단번에 인정하게 됨) | 도쿄세잔',
      channel:'비밀이야 bimirya', id:'lqL7inJ6xhA', start:null,
      reviews: [ {review:'도쿄 미슐랭 3스타 세잔 | SEZANNE TOKYO', channel:'기억안나영', id:'wwrdv2kV9oE', start:null} ]
    }
  ]
};
```

| 필드 | 설명 |
| --- | --- |
| `category` | 장소 유형: `hotel`(호텔) 또는 `michelin`(미쉐린 레스토랑). 기존 252개 호텔은 모두 `hotel`로 채워 두었습니다 |
| `region` | 권역 필터 값 **7종**: `일본`, `동남아`, `미주`, `유럽`, `중화권`, `오세아니아`, `중동·기타` |
| `area` | 국가 + 도시 (예: `일본 도쿄`, `태국 방콕`, `벨기에 브뤼셀`). 상세 주소는 넣지 않고 구글 지도 링크로 넘깁니다 |
| `kind` | `category:'hotel'`이면 **체인 필터 6종**(`메리어트`, `힐튼`, `하얏트`, `IHG`, `아코르`, `하이엔드·독립`), `category:'michelin'`이면 **음식 테마 4종**(`일식·스시`, `양식·파인다이닝`, `중식·딤섬`, `아시안·로컬`) |
| `grade` | 미쉐린 항목의 별 등급 표기: `미슐랭 3스타`, `미슐랭 2스타`, `미슐랭 1스타`, `빕구르망`, 영상에서 등급이 확인되지 않으면 빈 문자열 |
| `id` / `start` | 실제 유튜브 영상 ID와 등장 시점(초). 확인하지 못한 시점은 `null` |
| `official` | 브랜드 공식 사이트(체인·브랜드 단위). 호텔별 상세 URL은 자주 바뀌어 브랜드 공식 페이지만 연결합니다 |
| `reviews` | 같은 호텔을 다룬 다른 채널 리뷰. 카드에는 대표 1건만 뜨고, 상세 모달에서 `채널명 리뷰` 링크로 함께 열립니다 |

## 5. UI 동작

### 5-1. 전국 맛집 지도 — 기본 **접힘** + `지도로 펼치기` 토글

- 첫 화면에서는 지도 섹션의 **본문(`#map-body`)이 숨겨진 상태**입니다. 히어로의 검색창 → `장소 둘러보기` 카드가 바로 보입니다.
- 헤더 라인에는 **`지도로 펼치기` / `지도 접기` 토글 버튼 하나만** 있습니다(구글 지도로 나가는 외부 링크는 두지 않으며, 지도는 섹션 안의 `<iframe>`으로만 봅니다). 버튼을 누르면 접힌 본문이 열리고, 버튼 라벨이 **`지도 접기`**로 바뀌며 `aria-expanded`가 `true`가 됩니다.
- 접힌 동안에는 구글 지도 `<iframe>`에 `src`를 넣지 않아 **불필요한 로딩이 없습니다.** 펼칠 때 `render()`가 현재 필터 기준으로 `src`를 설정합니다.
- 접힌 상태에서 시·도 칩을 누르면 자동으로 지도가 펼쳐지고 해당 지역으로 이동합니다.

### 5-2. 필터

- **지역**: 전국 17개 시·도 칩 (`전체 지역` + 17개).
- **채널**: `subscribers`의 전체 채널(구독자 순).
- **음식 종류**: `listings`의 `kind` 값.
- **검색**: 가게명·지역·주소·종류·메뉴·채널명을 공백 단위로 AND 검색.
- **☆ 저장한 장소**: 카드의 별 버튼으로 저장/해제. `localStorage` 키 `hanip-guide:saved:v1`, 새 탭·새로고침에도 유지.

### 5-2-1. 해외지도 — 유형(호텔/미쉐린) → 체인·음식 테마 2단 필터

- 툴바 맨 앞에 **`전체` / `호텔` / `미쉐린 식당`** 유형 칩이 있습니다(해외지도에서만 보임, 다른 지도에서는 `hidden`).
- 유형을 고르면 두 번째 셀렉트가 함께 바뀝니다.
  - `호텔` → 셀렉트 라벨 `체인 · 브랜드`, 값 6종(메리어트·힐튼·하얏트·IHG·아코르·하이엔드·독립)
  - `미쉐린 식당` → 라벨 `음식 테마`, 값 4종(일식·스시·양식·파인다이닝·중식·딤섬·아시안·로컬)
  - `전체` → 라벨 `구분 · 테마`, 셀렉트 안에서 `호텔 체인`·`미쉐린 음식 테마` 두 그룹(`optgroup`)으로 묶어 보여줍니다.
- 유형을 바꾸면 채널 목록도 그 유형에 실제로 쓰인 채널만 다시 채워지고, 결과 제목이 `호텔 둘러보기` / `미쉐린 식당 둘러보기` / `호텔 · 미쉐린 둘러보기`로 바뀝니다.
- 카드 메타는 `도시 · 구분 · 별 등급`(미쉐린은 예: `프랑스 파리 · 양식·파인다이닝 · 미슐랭 3스타`), 상세 모달 메타도 같은 정보 + 영상 제목을 보여줍니다.
- 권역 칩·검색·지도·저장 기능은 호텔과 미쉐린에 공통으로 적용됩니다.

### 5-3. 카드와 지도 사이드바

- 카드 썸네일 = `https://i.ytimg.com/vi/{youtubeId}/hqdefault.jpg`, 클릭 시 모달에서 `youtube-nocookie` 임베드 재생.
- 지도 사이드바는 현재 필터 결과 목록. 항목을 누르면 `maps.google.com/maps?q=가게명+주소&output=embed`로 해당 위치를 띄웁니다.

## 6. 수정 시 주의사항

1. **상대경로 `./` 유지**: 이 페이지는 `/map/` 하위에서 서빙됩니다. 내부 링크·이미지는 `./`처럼 상대경로로 두세요. 공유 메타태그에는 `https://dailyfoodfighter.com/map/`으로 시작하는 이미지 절대 URL을 사용합니다.
2. **`<head>` OG 메타 보존**: 위 3절의 태그를 삭제·변경하지 마세요. 카카오톡 공유 미리보기가 깨집니다.
3. **`channel` 값은 `subscribers` 키와 문자열까지 일치**해야 카드가 렌더됩니다(불일치 항목은 조용히 제외됨).
4. **`youtubeId`는 11자리**여야 합니다. `start`는 초 단위 정수 또는 `null`.
5. **`region`은 17개 짧은 이름만**: `서울특별시`가 아니라 `서울`. 값이 다르면 지역 필터에서 빠집니다.
6. **구독자 10만 미만 채널은 추가하지 않습니다**(렌더 단계에서 제외됨). 단 미슐랭 등재 식당(`listings` 9번째 값)은 예외로, 채널 규모와 관계없이 표시됩니다.
7. 채널을 추가할 때는 ① `subscribers`에 채널과 구독자 수 ② `listings`에 그 채널의 실제 방문 영상·가게 정보를 **세트로** 넣습니다.

## 7. 데이터 검증 기준 (수록 원칙)

가짜 영상 ID나 확인되지 않은 가게를 넣지 않기 위해, 각 항목은 아래 중 하나로 확인한 것만 수록합니다.

1. **영상 설명의 가게명 + 주소**: 해당 영상 설명에 크리에이터가 직접 적은 `가게명`·`주소`(예: `📍가게명 | 주소`, `이름: … / 주소: …`)를 그대로 사용하고, 카카오·구글 지도에서 같은 이름/주소의 장소가 검색되는지 확인.
2. **영상에서 지목한 가게명**: 제목·설명·해시태그에 나온 가게명이 지도에서 해당 지역의 음식점으로 확인되는 경우.
3. **크리에이터가 건 장소 링크**: 설명에 붙은 네이버 플레이스/구글 지도 링크를 열어 상호·도로명주소 확인.
4. 주소가 확인되지 않으면 수록하지 않습니다.
5. 시장·축제 영상은 영상, 자막, 공식 설명에서 개별 점포 상호가 드러나고 촬영 지점의 주소를 확인한 경우에만 해당 점포를 수록합니다. 시장 이름이나 공통 주소만 확인되거나 지점이 모호하면 확인 대기 상태로 둡니다.

검증 스크립트로 확인하는 항목:

- `<script>` JS 파싱 오류 0건
- `subscribers` 키 개수 == 채널 수
- 모든 `listings[6]`(channel)이 `subscribers`에 존재
- `listings[8]`(grade)은 비었거나 `미슐랭 3스타`·`미슐랭 2스타`·`미슐랭 1스타`·`빕구르망`·`미슐랭 선정` 중 하나
- 모든 `listings[5]`(youtubeId)가 `[A-Za-z0-9_-]{11}`
- `정규화(가게명)+region` 중복 0건

## 유튜브 비공개·삭제 영상 자동 제외 (한입지도 + 한밤지도)

- **공통 기능**: 방문자가 `/map/`을 열면 한입지도와 한밤지도의 원본 영상 ID를 확인하고, 비공개·삭제되어 공개 접근이 불가능한 영상의 장소 카드·검색 결과·지도 위치·채널 필터를 자동으로 제외합니다.
- **같은 장소에 여러 리뷰**: 한입지도는 공개 상태인 다른 후보 중 구독자 수 기준 대표 영상을 다시 선정합니다. 한밤지도는 비공개 리뷰만 제거하고 다른 공개 리뷰가 남아 있으면 장소를 유지합니다.
- **안전장치**: HTTP 403/404는 접근 불가로 분류하되, YouTube API 장애·타임아웃·429·5xx, 임베드 정책(401)은 비공개로 확정하지 않습니다. 확인 실패 시 장소를 잘못 없애지 않습니다.
- **요청 비용 및 갱신 주기**: 영상 ID를 최대 30개씩 묶어 확인하고 Cloudflare 캐시 및 방문자 로컬 캐시를 각각 3시간 유지합니다. 비공개로 바뀐 영상이 사이트에서 사라지는 데 최대 약 3시간(다음 접속 시) 걸릴 수 있습니다. 공개로 복귀하면 다음 확인 시 다시 나타납니다. 원본 데이터는 유지됩니다.
- **구현 파일**: `functions/api/map/video-status.js` (Cloudflare Pages Function), `map/index.html` (양쪽 지도 필터 및 재선정).
- **선택적 정확도/속도 개선**: Cloudflare Pages 프로젝트의 환경 변수 `YOUTUBE_API_KEY`에 YouTube Data API v3 API 키를 설정하면, 요청당 최대 30개 영상의 공개 상태를 공식 API 1회로 확인합니다. **변수는 Cloudflare Secrets에만 저장하고 GitHub나 브라우저에 공개하지 않습니다.** 키가 없어도 YouTube 공개 oEmbed 인터페이스를 통해 작동하지만 일부 영상은 '확인 불가'로 남을 수 있습니다.
- **운영**: GitHub Actions·D1 사용하지 않습니다. Cloudflare Pages가 `functions/` 디렉터리를 함께 배포하는지 확인해야 하며, 정적 파일만 따로 올리는 배포 방식은 서버 API가 동작하지 않습니다.
