# 한입.한밤지도 (`/map/`) — 영상 속 맛집과 숙소 찾기

유튜브에 소개된 국내 맛집과 숙소를 지도에서 찾고 원본 영상을 확인할 수 있는 페이지입니다.
상단에서 **한입지도**와 **한밤지도**를 전환할 수 있습니다. 두 화면은 `/map/` 주소를 공유합니다.
외부 프레임워크 없이 동작하며, `main` 브랜치에 푸시하면 Cloudflare Pages가 자동 배포합니다.

---

## 1. 서비스 개요와 이전 경위

- **초기**: ChatGPT Sites로 만든 별도 사이트 `map.dailyfoodfighter.com`에서 운영.
- **현재**: 이 저장소의 `/map/` 경로(`https://dailyfoodfighter.com/map/`)로 이전 완료.
  - 블로그·혜택찾기·게임과 같은 도메인에서 관리되므로 검색 노출과 운영이 한곳으로 모입니다.
  - 옛 주소 `map.dailyfoodfighter.com`은 **301 리다이렉트**로 새 주소에 연결합니다.
    (리다이렉트는 Cloudflare 대시보드의 Redirect Rules에서 관리하며, 이 저장소에는 설정 파일이 없습니다.)
- **한입지도**: 구독자 10만 명 이상 채널이 실제로 방문·소개한 국내 식당을 수록합니다.
- **한밤지도**: 선정한 채널의 원본 영상이 객실이나 숙박 경험을 직접 소개하는지 확인하고, 정확한 지점명과 주소를 대조합니다. 게스트하우스로 운영되는 숙소는 수록 대상에서 제외합니다. 구독자 10만 명 이상 채널과 별도로 지정한 숙소 리뷰 채널을 포함합니다. 여러 장소를 다룬 영상은 확인 가능한 숙소 구간에 연결합니다. 한 숙소에 여러 원본 리뷰가 있으면 `reviews`에 추가하면 됩니다. 채널을 선택하면 해당 채널의 리뷰가 카드에 표시됩니다.
- **숙소 영상 확인 범위**: 채널별 공개 일반 영상, 쇼츠, 다시보기 목록을 확보한 뒤 영상별로 확인합니다. 같은 영상에 여러 숙소가 나오면 숙소별 주소와 확인 가능한 등장 시점을 기록합니다. 목록을 수집한 단계와 영상 전체를 확인한 단계는 구분합니다.

## 4. 데이터 구조

### 4-1. `subscribers` — 채널과 구독자 수

```js
const subscribers = {
  "쯔양": 13500000,
  "성시경 · 먹을텐데": 2360000,
  // … 총 103개 채널
};
```

- **키** = 화면에 표시하는 채널 이름(카드의 `source`·드롭다운 라벨과 같은 문자열).
- **값** = 확인 당시 공개된 구독자 수. 10만 미만 채널은 수록하지 않습니다.
- 채널 드롭다운은 이 객체를 **구독자 수 내림차순**으로 그립니다(영상이 중복 정리된 채널도 목록에는 남습니다).

### 4-2. `listings` — 식당 목록 (8컬럼 배열)

```js
["영선네 국수", "경기", "경기 의정부시 태평로73번길 20", "면요리", "비빔국수", "63yWfN4M-kw", "푸디랜드 FoodieLand", null]
```

| # | 필드 | 설명 |
| --- | --- | --- |
| 0 | `name` | 가게 이름 |
| 1 | `region` | 시·도 **짧은 이름** (`서울`,`부산`,`경기`,`충남`,`세종` … 총 17종). 필터가 이 값으로 동작 |
| 2 | `area` | 상세 주소 또는 동네/랜드마크 표기 |
| 3 | `kind` | 음식 종류 (`국밥`,`면요리`,`중식`,`일식`,`양식`,`분식`,`고기`,`해산물`,`베이커리`,`카페`,`한식`) |
| 4 | `menu` | 대표 메뉴 |
| 5 | `youtubeId` | 유튜브 영상 ID **11자리** |
| 6 | `channel` | `subscribers`에 있는 채널 이름과 **정확히 일치**해야 함 |
| 7 | `start` | 영상 시작 초(정수) 또는 `null`. 값이 있으면 카드에 "1:40부터" 배지와 `t=` 링크가 붙음 |

### 4-3. 중복 식당 → 대표 유튜버 1개만 표시

같은 가게가 여러 채널 영상에 나오면 **구독자 수가 가장 많은 채널 1개만** 남깁니다. 두 단계로 보장합니다.

1. **데이터 단계**: `listings`를 만들 때 `정규화(가게명) + region`이 같으면 구독자 수가 큰 쪽만 남김.
2. **렌더 단계**: `representativePlaces()`가 실행 시점에 같은 키로 그룹화하고, 구독자 수가 큰 항목을 대표로 선택(동률이면 `start`가 있는 쪽).
   → 나중에 `listings`에 중복을 추가해도 화면에는 항상 1곳만 나옵니다.

```js
const key = [name, region].map(v => v.normalize('NFKC').toLowerCase().replace(/\s+/g,'')).join('|');
```

## 5. UI 동작

### 5-1. 전국 맛집 지도 — 기본 **접힘** + `지도로 펼치기` 토글

- 첫 화면에서는 지도 섹션의 **본문(`#map-body`)이 숨겨진 상태**입니다. 히어로의 검색창 → `장소 둘러보기` 카드가 바로 보입니다.
- 헤더 라인에는 **`지도로 펼치기` / `지도 접기` 토글 버튼 하나만** 있습니다(구글 지도로 나가는 외부 링크는 두지 않으며, 지도는 섹션 안의 `<iframe>`으로만 봅니다). 버튼을 누르면 접힌 본문이 열리고, 버튼 라벨이 **`지도 접기`**로 바뀌며 `aria-expanded`가 `true`가 됩니다.
- 접힌 동안에는 구글 지도 `<iframe>`에 `src`를 넣지 않아 **불필요한 로딩이 없습니다.** 펼칠 때 `render()`가 현재 필터 기준으로 `src`를 설정합니다.
- 접힌 상태에서 시·도 칩을 누르면 자동으로 지도가 펼쳐지고 해당 지역으로 이동합니다.

### 5-2. 필터

- **지역**: 전국 17개 시·도 칩 (`전체 지역` + 17개).
- **채널**: `subscribers`의 전체 채널(구독자 순).
- **음식 종류**: `listings`의 `kind` 값.
- **검색**: 가게명·지역·주소·종류·메뉴·채널명을 공백 단위로 AND 검색.
- **☆ 저장한 장소**: 카드의 별 버튼으로 저장/해제. `localStorage` 키 `hanip-guide:saved:v1`, 새 탭·새로고침에도 유지.

### 5-3. 카드와 지도 사이드바

- 카드 썸네일 = `https://i.ytimg.com/vi/{youtubeId}/hqdefault.jpg`, 클릭 시 모달에서 `youtube-nocookie` 임베드 재생.
- 지도 사이드바는 현재 필터 결과 목록. 항목을 누르면 `maps.google.com/maps?q=가게명+주소&output=embed`로 해당 위치를 띄웁니다.

## 6. 수정 시 주의사항

1. **상대경로 `./` 유지**: 이 페이지는 `/map/` 하위에서 서빙됩니다. 내부 링크·이미지는 `./`, `og-hanip-hanbam.jpg`처럼 상대경로로 두세요. `/map` 없는 절대경로(`/og-hanip-hanbam.jpg`)를 쓰면 깨집니다.
2. **`<head>` OG 메타 보존**: 위 3절의 태그를 삭제·변경하지 마세요. 카카오톡 공유 미리보기가 깨집니다.
3. **`channel` 값은 `subscribers` 키와 문자열까지 일치**해야 카드가 렌더됩니다(불일치 항목은 조용히 제외됨).
4. **`youtubeId`는 11자리**여야 합니다. `start`는 초 단위 정수 또는 `null`.
5. **`region`은 17개 짧은 이름만**: `서울특별시`가 아니라 `서울`. 값이 다르면 지역 필터에서 빠집니다.
6. **구독자 10만 미만 채널은 추가하지 않습니다**(렌더 단계에서 제외됨).
7. 채널을 추가할 때는 ① `subscribers`에 채널과 구독자 수 ② `listings`에 그 채널의 실제 방문 영상·가게 정보를 **세트로** 넣습니다.

## 7. 데이터 검증 기준 (수록 원칙)

가짜 영상 ID나 확인되지 않은 가게를 넣지 않기 위해, 각 항목은 아래 중 하나로 확인한 것만 수록합니다.

1. **영상 설명의 가게명 + 주소**: 해당 영상 설명에 크리에이터가 직접 적은 `가게명`·`주소`(예: `📍가게명 | 주소`, `이름: … / 주소: …`)를 그대로 사용하고, 카카오·구글 지도에서 같은 이름/주소의 장소가 검색되는지 확인.
2. **영상에서 지목한 가게명**: 제목·설명·해시태그에 나온 가게명이 지도에서 해당 지역의 음식점으로 확인되는 경우.
3. **크리에이터가 건 장소 링크**: 설명에 붙은 네이버 플레이스/구글 지도 링크를 열어 상호·도로명주소 확인.
4. 주소가 확인되지 않으면 수록하지 않습니다.
5. 시장·축제 영상은 영상, 자막, 공식 설명에서 개별 점포 상호가 드러나고 촬영 지점의 주소를 확인한 경우에만 해당 점포를 수록합니다. 시장 이름이나 공통 주소만 확인되거나 지점이 모호하면 확인 대기 상태로 둡니다.

검증 스크립트로 확인하는 항목:

- `<script>` JS 파싱 오류 0건
- `subscribers` 키 개수 == 채널 수
- 모든 `listings[6]`(channel)이 `subscribers`에 존재
- 모든 `listings[5]`(youtubeId)가 `[A-Za-z0-9_-]{11}`
- `정규화(가게명)+region` 중복 0건
