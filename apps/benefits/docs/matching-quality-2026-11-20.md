# 혜택찾기 지역·연령·소득 맞춤추천 정확도 보강 — 2026-11-20

## 범위와 운영 원칙

인천광역시를 맞춤 조건으로 입력해도 경상북도·곡성군 등 타 지역 사업이 노출되는 현상을 개선한다. 기존 2026-11-20 Worker/D1와 공공 API 수집기, 저장된 공고는 그대로 둔다. 개인 프로필의 시·도·시군구·자녀 출생연도·소득비율은 **브라우저 내에서만 비교**하고 새 서버 요청 파라미터에 개인조건을 넣지 않는다.

- 지역 공개 원문: `region_sido`·`region_sigungu`가 공식 저장돼 있으면 우선하고, 없으면 **공고 제목**에 나온 명확한 지역 접두어만 해석한다. 기관 소재지는 신청자 거주요건이 아니다.
- 구체적인 분류: `LOCAL`(확실한 지역), `NATIONAL`(전국·공통 또는 엄격히 알려진 전국 기본제도명), `UNKNOWN`(근거 없음). 중복 지역명(중구·서구·남구·북구·동구·고성군)은 상위 시·도 없이는 추측하지 않는다.
- 공식 제목과 원천 필드로 지역이 확정되면 다른 지역의 신청자는 제외. 지역 확인이 안 되는 공고는 자격불일치로 단정하지 않되, **기본 추천에는 섞지 않고 별도 선택에서 조회**한다.
- 디폴트 개인 지역 설정 시 **내 지역·전국만**. 다른 버튼은 **지역 확인 필요**와 **전체 지역 비교**. 지역을 입력하지 않은 사람은 기존 전체 조회 유지.
- **17개 시·도, 시·군·구/자치구 등의 중복 없는 명칭 236개**를 참고 지도로 사용. 기존 공개 자료의 부산 누락을 발견하여 전국 17개 시·도를 포함한 자료로 교체했다. 2026-07-01 인천 행정체계 개편 명칭(제물포구·영종구·검단구·서해구) 추가. 중복 지역명은 상위 시도 없이 판정하지 않는다. 최신/모호한 경계·주소는 공식 공고를 재확인.
- 전국 공통 명칭은 부모급여·가정양육수당·영유아보육료·유아학비·아동수당에 한정. **단순히 원문이 비어 있다는 이유로 전국 지원으로 추정하지 않음.** 지역 특화 지원은 제목 접두어가 있으면 LOCAL로 분류.
- 자녀 출생연도는 보수적 연령 판정. 경계월령·시설 이용·미입력 자녀는 `CHECK`; 확실한 불일치만 `NO`. 조건값이 모든 공고에 존재하지 않기 때문에 국가/지방 지원을 개인별로 100% 자동 판정할 수 없다.
- 중위소득 비율 `50.5%` 같은 소수 값의 구간 공백을 수정함. 공식 `JA020x` 코드의 복수 구간은 OR이며, 소득비율 미입력 시 확인 요청. 소득액 자체를 임의 추정하지 않음.
- 접수 시작 전 `CHECK` 표시, 확정 마감일 경과 시 `NO` 처리; 날짜 계산 한국시간 기준.

## 수정 코드

- `src/lib/districts.ts`: 이름이 고유한 시·군·구→시·도 테이블.
- `src/lib/territory.ts`: `classifyRegion`, `regionFit` 및 기존 `effectiveSido`, `regionMismatch` 호환.
- `src/lib/region-visibility.ts`: 모드별 공개 공고 노출 정책.
- `src/lib/matching.ts`: 지역 확인 미비 표시, 전국 혜택 가시성, 소득·시작일 경계.
- `src/routes/+page.svelte`: 맞춤 필터 3가지 모드, 시·도 선택에 연동되는 시·군·구 **선택 목록**, 개별 카드 지역 표시, 무결과 시 지역 미확인 안내, 자녀 출생연도·중위소득 입력 설명.
- `tests/region-quality.test.mjs`: 경상북도·곡성군·연수구·제주·인천형·2026 인천 개편·중구 중복 등과 자녀·소득·시작일 회귀.
- `tests/matching.test.mjs`: 기존 연령·주거·가구원·조건코드 안전성 회귀 유지.

## 개인정보·API 예산·비운영 영향

변경은 **정적 웹 프론트엔드**에 국한된다. Cloudflare Worker/D1 migration·운영 DB 행 편집·Gov24/Bizinfo 전체 재수집·Docker 수집기 재시작·API 승인 호출량·GitHub Actions 실행은 **필요 없다**. 추출된 지역은 자격 `LIKELY` 보증 근거가 아니며, 카드에 공식 기관 최종 확인 안내를 계속 제공한다.

## 로컬 iMac 검증과 웹 배포

```bash
cd ~/policy-benefit-matcher
git pull --ff-only
npm test
npm run check
/bin/bash scripts/release-personalization-imac.sh
```

해당 릴리스 스크립트는 블로그 `dailyfoodfighter`의 `benefits/` 범위만 빌드·스테이징·커밋·push한다. Cloudflare Pages GitHub 연동에서 Production 배포 완료 여부를 별도로 확인해야 최종 완료다. **이 문서 기록 시점에는 새 보강 코드를 iMac에서 다시 빌드·배포했다고 주장하지 않는다.**

### 배포 후 수동 회귀 예시

1. 기존 저장된 지역 프로필을 `인천광역시`로 설정하고 `내 조건과 불일치 제외`를 켠다. `내 지역·전국만`이 기본이며, `경상북도 아이돌봄 본인부담금 지원`, `곡성군 아이돌봄서비스 본인부담금 지원` 등은 노출되지 않아야 한다.
2. `지역 확인 필요` 탭에서 공식 지원 지역이 확인되지 않은 공고를 별도로 확인한다. `전체 지역 비교`에서는 타 지역 공고도 보고 `입력 조건과 불일치`를 점검한다.
3. 전국 기본제도 `부모급여 지원`, `가정양육수당 지원`이 D1에 수록된 경우 인천 사용자의 `내 지역·전국만`에서도 보일 수 있어야 한다. 검색 결과 1,000건 구간 제한으로 늦게 나오는 공고는 추가 페이지 확인.
4. 자녀가 2025년생이면 부모급여를 바로 제외하지 않고, 2021년생 자녀 1명만 있다면 전국 기본 부모급여는 연령 불일치로 제외. 2024년생은 정확한 생월·생일 확인 대상으로 남긴다.
5. 소득비율 `50.5%`와 공식 JA0202 구간을 비교할 때 중간 소수 값으로 허위 불합격하지 않아야 한다.
6. 모든 대상자의 **최종 신청 가능 여부는 원문 확인**이 필요하다. 제목 지역 추출이 곧 신청 지역 자격의 완벽한 공식 확인은 아니다.

## 정확도 검증 상태

- 소스 코드에 신규 지역 처리와 UI를 반영했고, 인천/타 지역/전국/미확인 로직에 대한 **독립 V8 스모크 검사(주요 사례)**는 의도대로 통과함.
- **실제 iMac `npm test`, `npm run check`, Cloudflare Pages 게시 확인은 신규 코드 기준 아직 미실행.** 기존의 37 JS + 64 Python + 3 Worker 테스트 PASS는 이전 버전의 결과이며, 이 보강의 빌드 성공으로 재사용하면 안 됨.
- 전국 전체 공고의 기계 판독이 100% 달성된 것은 아님. 원본 지역/소득/연령 메타데이터 누락을 영구적으로 대체할 수 없으며, 계속 조회 가능한 별도 `지역 확인 필요` 집합으로 남김.
