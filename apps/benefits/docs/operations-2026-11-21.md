# 11월 21일 운영 작업

11월 20일 기준 공식 원본 12,238건을 먼저 별도 테이블에 적재하고, 이후 확보한 자료는 변경된 부분만 반영한다. 운영 공고를 제공하는 `programs`는 이 작업의 적재 대상이 아니다.

## 1. 한도 해제 확인과 기준본 적재

- **오전 9시 KST 이후** Cloudflare Dashboard에서 D1 일일 읽기 차단 해제, 남은 쓰기 행 수와 저장 공간을 확인한다. 차단이 계속되면 원격 SQL을 실행하지 않는다.
- 작업 폴더의 `audit-artifacts/staging-baseline-20261120/`을 사용한다. 이 폴더는 Git에 넣지 않은 고정 기준본이다. `manifest.json`과 `sha256.json`을 대조한다. 예상 목록은 정부24 10,891건과 기업마당 1,347건, SQL 파일 284개다. 정부24 상세 4,440건, 지원조건 4,439건, 두 원본이 모두 있는 공고 4,439건이다.
- 최초 적재라면 `migrations/0003_official_source_snapshots.sql`로 별도 테이블을 준비한다. 기준본의 manifest에 명시된 파일만 순서대로 적재한다. 기존 `stage-official-to-d1-imac.sh --apply-remote`는 원본을 다시 읽어 SQL을 생성하므로 11월 20일 고정 기준본을 적용할 때 그대로 실행하면 안 된다.
- 처리한 파일과 성공한 마지막 번호, 응답의 읽기·쓰기 행 수를 기록한다. 한도 접근, 429, 실패가 발생하면 중단한다. 재개할 때 동일한 SQL은 재실행할 수 있다. 로컬 SQLite 두 차례 적용에서 12,238건 삽입 후 0건 변경을 확인했다.
- 적재 전후 별도 스테이징의 출처별 총건수와 정부24 상세·조건 확보 건수를 비교한다. 구조화된 변경 응답으로 신규·변경·건너뜀을 구분할 수 없으면 각각 미확인으로 적는다. D1의 쓰기 행 수에는 인덱스 갱신이 포함될 수 있으므로 공고 수로 해석하지 않는다. `programs`에는 적재 명령을 보내지 않는다.

## 2. 이후 확보 자료만 증분 반영

- 상세와 지원조건을 모두 확보하지 못한 정부24 공고는 11월 20일 기준 **6,452건**이다. 새로운 수집은 정부24의 KST·UTC 일일 한도와 iMac의 기존 체크포인트를 확인한 뒤 진행한다. 전체 목록이나 이미 저장된 상세를 다시 받지 않는다. 수집용 영속 볼륨과 호출량 장부를 유지한다.
- 실제 새로 확보된 상세·지원조건과 공식 변경분만 별도 테이블에 추가한다. `source + source_id`와 원본 내용 해시로 비교한다. 동일 해시는 건너뛰고, 새 배치에 없는 상세·조건은 기존 값을 보존한다. 공고의 부재만으로 삭제하지 않는다.
- 기업마당 1,347건은 이번에 연결한 API가 보고한 목록이다. 과거 약 3,000건과의 차이는 조회 시점, 과거 공고 포함 여부, 다른 제공 API인지부터 확인한다. 근거를 확보하기 전에는 부족분으로 계산하지 않는다.

## 3. 아직 검증·추가할 항목

- **운영 검색 누락**은 승인된 운영 스냅샷을 별도로 확보한 뒤 로컬에서 ID를 대조한다. 공식 원본에서 재구성한 12,238건 및 32개 조건 조합에서 누락·초과·중복 0건을 확인했지만, 운영 D1 사본을 전수 비교한 결과는 아직 없다. 재실행 방법은 [검색 누락 감사](search-coverage-audit.md)에 있다.
- **실제 D1 읽기량**은 먼저 소량의 표본으로 인덱스와 `rows_read`를 확인한다. 대시보드에서 캐시 적중률·키워드 검색·수집 단계를 따로 본다. 500만 행 이내의 실제 이용자 수와 수집 절감량은 실측 후 갱신한다. 로컬 SQLite 실행 명령 수는 D1 과금 행 수가 아니다.
- **자격 근거 보강**은 공식 상세·지원조건을 확보한 뒤 소득 기준 연도·가구원, 생년월일 경계, 사업자·업력·매출 예외 순으로 확인한다. 근거가 모호한 공고는 ‘자격 추가 확인 필요’에 둔다. 검증한 필드를 운영 `programs`로 옮기는 작업은 별도 검토·승인 대상으로 둔다.
- **운영 검색 점검**은 인천·연수구에서 전국 대표 1건과 독립된 인천 추가지원의 구분, 타지역 전용 공고 제외, 지역 미확인 보기, 다음 페이지를 우선 확인한다. 11월 20일 프론트에서 소관기관 직접 입력을 제거했으며 기관 이름은 카드에 표시한다.
- **수집기와 Worker 후속 검증**은 승인된 배포·운영 작업으로 분리한다. 스테이징 확인만을 위해 수집기 재시작, Worker 재배포, GitHub Actions 실행을 하지 않는다. 원본 캐시 재사용이 실제로 절감하는 호출 수와 증분 예약 회차 성공은 운영 로그에서 확인한다.
