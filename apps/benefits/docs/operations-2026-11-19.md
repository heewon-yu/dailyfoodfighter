# 혜택찾기 운영 인계 — 2026-11-19

## 운영 정책 (사용자 확정)
- 정부24 발급키 일일 승인량 **10,000회**, 기업마당 **1,000회**. 기본 예산 **90%** = 각각 **9,000회 / 900회** (환경변수 API_BUDGET_PERCENT 80~90 변경 가능).
- 각 외부 API 호출 직전에 Docker 영속 볼륨의 `api-usage.json`에 예약·기록. 복수 실행/재시작 간 공유, 파일잠금. KST·UTC 일별 창 모두 보호. **동일 키를 외부 스크립트가 사용하면 그 호출까지 자동 합산되지는 않음**.
- **수집 시간은 한국시간 10:00, 12:00, 14:00, 16:00, 18:00**. Docker 서비스는 상주, 슬롯에만 실제 수집. 재부팅 후 진행되지 않은 당일 최근 슬롯은 1회 보충.
- 정부24 최초·일일 전체 목록은 작은 페이지 묶음으로 진행하고 미완료 시 다음 슬롯 이어받기. 전체 목록 완료 후 해당일 다음 슬롯은 한정된 변경 후보 페이지를 탐색. 기업마당도 1페이지 신규 우선 조회 + 옛 페이지 커서 순환. *공식 변경분 조회 API가 확인되지 않았으므로 목록 API 요청까지 0으로 만들 수는 없음*. 변경 해시는 D1에서 비교하여 불필요한 쓰기 최소화.
- 정부24 상세조회는 D1에 저장된 **미보강 사업**을 우선순위로 조회하는 인증된 큐를 이용. 상세/조건조회도 하루 API 예산에 포함. 오류나 예산 소진 시 다음 슬롯/다음날 재시도.
- 확정된 접수 마감은 DB에 **영구삭제**. Worker에서 KST 자정의 *삭제 전용* Cron과 10·12·14·16·18시 정리 수행; API 수집은 자정에 실행하지 않음. 수집으로 감지된 명시적 CLOSED도 D1에서 DELETE 처리.
- 원본 API의 일시적인 목록 누락만으로 삭제하면 안 됨. 정부24 전체 목록에서 2회 연속 안전한 완전 스캔으로 사라진 경우만 삭제. UNKNOWN 기간·일시 장애 데이터는 근거 없이 삭제하지 않음.

## 사용자 필터
- 시도 정규화 + 공고 제목의 명시적인 지역 범위. 제주·경북 등 특정 지역은 다른 시도 사용자에게 노출하지 않음. 전국·실제 범위 미확인 공고는 자격 확인 안내.
- 공식 정부24 조건 코드로 중위소득·다자녀·무주택·업력/창업·직업 항목과 입력값 비교. 아동수, 임신 여부, 혼인, 주거형태, 고용 상태에 대한 확정 불일치는 제외, 미확인 자격은 CHECK.
- 개인 프로필은 브라우저에만 저장. 첫 50개의 API 결과가 다른 조건으로 전부 탈락해도 다음 페이지를 추가로 검사해 최대 50개의 표시 후보 확보(한 번에 최대 20개 원격 페이지 조회).
- 탐색필터 14개 세부항목 및 모바일 표시. 필터는 서버에서 공고의 제목/요약을 좁힌 뒤 브라우저에서 최종 자격 비교.
- **필터 판정은 자동 수급자격 보증이 아님**. 단순 키워드로 본인 자격을 확정하면 안 됨.

## iMac 출시 실행
- `cd ~/policy-benefit-matcher && bash scripts/release-benefits-imac.sh`
- 자동 수행: 원격 fast-forward, Docker Python unittest, npm JS 회귀 및 Svelte check, Worker typecheck, 블로그 `benefits/` 정적 빌드/커밋/푸시, Wrangler Worker 배포, D1 확정 마감 기록 영구삭제, Docker collector 재기동.
- **Github Actions 사용 금지**. Cloudflare Pages가 GitHub 커밋을 자동 배포하도록 연결돼 있어야 함. 배포 연결이 아니라면 Pages 직접 배포 필요.
- iMac 로컬 .env에 기존 발급 키와 `INGEST_URL`, `INGEST_TOKEN`이 필요. API 키나 토큰을 채팅·GitHub에 올리지 말 것.
- Docker Desktop 실행 및 Cloudflare `wrangler login` 필요. 실행 스크립트가 실패하면 로그의 해당 단계 확인 후 그 이후 단계는 미완료로 취급.
