Contact and report an error

Use our GitHub issue tracker to report an incorrect figure, source or service problem. Include the page URL, steps to reproduce the issue and the result you expected.

Create an issue on GitHub

A GitHub account is required. Submitted issues are public. Do not include passwords, API keys, phone numbers, detailed health information or other personal data. Remove personal information from screenshots before posting.

What to include

  • The affected page URL and the sentence or figure to correct.
  • A link to official data or original research, if available.
  • For service problems, your device, browser and reproduction steps.

Track submissions and replies on GitHub. This page does not collect or send a separate contact form.
