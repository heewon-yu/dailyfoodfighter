# DailyFoodFighter 마스터 프롬프트 V4 — 서비스 검색·이용자 성장 개정

2026-11-27 사용자 최종 지시를 원본 V4보다 우선 적용한다. 원본의 전체 블로그 본문 개선 요구는 이 개정으로 철회한다.

## 핵심 목표

생활지도에 연결된 각 공개 서비스를 독립적인 검색 진입점으로 운영하고, 검색 노출·클릭·신규 이용자·실사용·재방문을 늘리며 Google AdSense 신청에 필요한 사이트 구성을 준비한다. 색인·순위·트래픽·광고 승인은 검색엔진과 Google의 결정이므로 구현 완료와 실제 성과를 구분해 기록한다.

## 확정된 화면과 범위

- 메인 최종 브랜드는 **쓸모집**이며 설명은 **일상에 필요한 도구와 정보를 한곳에**로 한다. 이전 생활지도 명칭 지시는 이 결정으로 대체한다. DailyFoodFighter 도메인·운영 브랜드와 인증값은 유지한다.

- 메인은 생활지도부터 시작하며 그레이 팔레트를 메인에만 적용한다. 기존 계산기의 코랄과 각 서비스 고유 디자인은 유지한다.
- 생활지도 안내 박스는 제거하고 사이트 소개·콘텐츠 작성 원칙·문의·개인정보·공식 X 링크를 하단 푸터 한 곳에 모은다.
- 식재료 영양 계산 카드는 메인에서 제거한다. 기존 서비스 URL과 검색 자산은 보존한다.
- 웹게임은 메인에서 허브 카드 하나로 모으고 허브 안에서는 각각 이모지 카드로 연결한다.
- /hotel/은 힐튼 포인트 숙박이며 StayPoint에 연결한다. /cal/#hotel 및 /cal/hotel/은 별도 계산기 기능이다.
- 기존 한국어·영어 블로그는 유지하며 본문 재작성·영양 수치 개편·건강 주장 전수 수정은 수행하지 않는다. 준비 중이던 미배포 수정본은 운영에 포함하지 않는다.

## 수행할 작업

1. 각 서비스의 검색 가능한 독립 URL·고유 title·description·H1·canonical·공유 정보·사이트맵·robots·내부 탐색을 점검하고 수정한다. 계산기 12종·게임 개별 페이지·지도·항공·정책복지·호텔의 검색 진입 의도를 구분한다.
2. 실제 제공 기능과 일치하는 서비스 소개·사용법·입력 조건·FAQ·관련 서비스 연결을 보강한다. 중복·도어웨이 페이지와 근거 없는 지역/키워드 페이지는 만들지 않는다.
3. 공개 적격 URL의 색인 차단·오류·soft 404·중복 canonical·고아 페이지를 해결한다. Search Console·Naver·Bing에서 접근 가능한 계정과 제출 상태를 확인하고 확인하지 못한 항목은 보고한다.
4. 서비스별 핵심·롱테일 검색어와 랜딩을 매핑한다. 실제 검색어·노출·CTR·평균순위로 개선 우선순위를 갱신한다.
5. GA4 등의 실제 설정을 확인하고 서비스 진입·기능 이용·외부 이동을 개인정보 없이 측정한다. 활성 사용자·신규·재방문·참여·자연검색 유입을 정의하고 광고·분석 동의 설정을 점검한다.
6. 속도·모바일 사용성·접근성·검색 크롤러 렌더링을 개선한다. 기능·데이터·URL·인증 설정을 보존한다.
7. AdSense 공식 정책에 따라 탐색성·운영자 소개·실제 문의 채널·개인정보 및 쿠키 고지·정책 문서·광고와 서비스 동선 구분을 정비한다. 실제 신청·심사·승인은 증거 없이 완료로 표시하지 않는다.
8. 기존 무료 인프라와 로컬 스크립트를 사용해 반복 SEO 검사·깨진 링크·사이트맵·성과 비교를 재실행 가능하게 만든다. 요청 없는 자동 메시지 발송은 하지 않는다.
9. GitHub Actions 신규 실행 없이 Cloudflare 기존 운영 프로젝트에 배포하고 운영 URL·주요 기능·DB 연결을 확인한다. 최신 main 데이터와 사용자 변경을 덮지 않는다.
10. 변경 파일·배포 ID·검증 범위·성과 기준선·남은 일·외부 권한 필요 항목을 보고서로 남기고 GitHub와 Notion에 저장한다. 보관 브랜치 저장과 운영 main 반영을 구분한다.

## 완료 증거

서비스 전체 URL별 상태·메타·canonical·robots·사이트맵·기능 응답 검사, 운영 배포 결과, 검색엔진 제출 및 접근 상태, 측정 설정과 지표 정의, AdSense 준비 체크 결과, GitHub·Notion 기록이 필요하다. 검색 순위 상승·유입 증가·승인은 시간 경과 후 실측으로 별도 평가한다. 확인되지 않은 항목은 미완료·미확인 사유와 다음 조치를 적는다.
