# DailyFoodFighter: 초기 상태 점검

점검일: 2026-11-27 (KST)
기준 저장소: `heewon-yu/dailyfoodfighter`, `main`의 `3c733725`

## 확인한 사실

- 저장소는 Jekyll 기반 정적 사이트이며 공개 저장소의 `main`을 별도 작업 브랜치로 복제했다.
- 운영 홈페이지 `/`는 영양학 게시글 목록을 중심으로 구성되어 있고, 사이트 제목도 식재료 영양 가이드 중심이다.
- `/air/`는 네이비 `#0f2340`, 블루 `#2563eb`, 밝은 회색 배경 `#f5f7fb`, 흰 카드와 둥근 모서리를 사용하는 별도 스타일시트가 있다.
- `_posts/`에는 132개 게시글이 있으며 front matter 기준 한국어 66개, 영어 66개다. 기존 영양 게시글 경로는 `/posts/:title/` 규칙을 사용한다.
- `/cal/`, `/map/`, `/air/`, `/benefits/`, `/games/`, `/nutrition-calculator/` 경로가 코드에 있다. `/hotel/`은 저장소에 없었고 운영 도메인 요청은 404를 반환했다.
- `/cal/`에는 이미 호텔 포인트 비교 기능(`#hotel`)이 있다. 새 `/hotel/` 안내 페이지는 해당 기능으로 바로 연결한다.
- 기존 사이트에는 GA4 측정 설정, 검색엔진 인증값, 광고 관련 파일, `robots.txt`, `sitemap.xml`이 있다. 이 변경에서 해당 인증 및 광고 설정은 수정하지 않았다.
- 기존 사이트맵은 주요 서비스 경로와 게시글을 포함하도록 작성되어 있다. 생활지도 변경과 함께 `/blog/`, `/editorial-policy/`, `/hotel/` 경로를 추가했다.

## 아직 확인하지 않은 외부 지표

Search Console, Naver Search Advisor, Bing Webmaster Tools, GA4 및 Cloudflare 분석 계정에는 이 작업 환경에서 연결된 보고서가 없다. 따라서 노출, 클릭, CTR, 순 방문자, 신규·재방문자, 광고 심사 상태를 확인하지 않았으며 수치 기준선을 임의로 만들지 않는다.

## 구현 검증 제한

현재 실행 환경에는 Jekyll gem이 설치되어 있지 않고 저장소에도 Gemfile이 없다. 따라서 이 작업에서 Jekyll 빌드는 실행하지 못했다. 변경사항의 Git 공백 검사는 통과했다. 운영 배포 전 Jekyll 빌드 및 실제 페이지 검증이 필요하다.

## 진행 중인 URL 확인

사용자는 호텔 서비스 주소가 기존 도메인의 다른 하위 경로일 수 있다고 안내했다. 현재 운영 중 `/hotel/`은 404였으므로 `/hotel/` 안내 페이지에서 저장소의 호텔 포인트 계산 기능(`/cal/#hotel`)으로 연결했다. 실제 연결해 둔 서비스의 주소가 따로 확인되면 생활지도 카드와 안내 링크를 해당 주소로 맞춘다.
