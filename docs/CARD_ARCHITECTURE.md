# 이달의 카드지도(/card/) 아키텍처

`https://dailyfoodfighter.com/card/` — 카드 발급 캐시백과 용도별 추천 카드를 정리한 참고용 비교 페이지.
카드 발급·결제를 대행하지 않으며, 발급 실적 수수료를 받지 않는다.

- 파일: `card/index.html` (Jekyll 미가공 정적 HTML, `_config.yml`의 include 없이 그대로 복사됨), `card/og-card.jpg`
- 공용 스타일: `/air/assets/milemap-app.css`를 불러오고, `card/index.html`의 인라인 `<style>`에서 **딥 앰버/골드 팔레트**(`--gold:#b45309`, `--gold-600:#d97706`, `--gold-700:#92400e`)로 CSS 변수만 덮어쓴다. `/air/`(블루)·`/hotel/`(퍼플)·`/macro/`(에메랄드)·`/cal/`(코랄/인디고)와 겹치지 않게 하기 위한 규칙이다.
- 인덱싱: `<meta name="robots" content="index, follow">`, canonical `https://dailyfoodfighter.com/card/`, `sitemap.xml` 등록, IndexNow 제출(`scripts/ping-indexnow.sh`).

탭과 유형은 `?tab=issue|top`, `?type=<slug>` 쿼리로 딥링크되며, JS는 탭 전환·유형 전환만 담당한다(데이터는 모두 HTML에 정적으로 존재 → 크롤러가 읽을 수 있음).

## 데이터 구조

카드 1건은 다음 필드를 가진다(HTML `article.card-item`).

| 필드 | 설명 |
| --- | --- |
| `name` / `issuer` | 카드명·발급사 |
| `annualFee` | 국내전용/해외겸용 연회비 (예: `국내 47,000원 / 해외 49,000원`) |
| `preMonth` | 전월실적 (`없음` 또는 `50만원 이상`) |
| `preMonthInOut` | 전월실적 포함/제외 요약 — 포함: 일시불·할부 / 제외: 세금·공과금·아파트관리비·상품권·선불충전·현금서비스·연회비(카드사 공통 기준, 카드별 예외는 약관 확인) |
| `benefits[]` | 핵심 혜택 2~3개 |
| `badges[]` | 라운지·등급·수수료 면제 등 서브 정보(예: `더라운지 연 2회`) |
| `detailUrl` | 카드고릴라 카드 상세(카드사 공시·이용조건 기반) `https://www.card-gorilla.com/card/detail/{idx}` |

발급 캐시백(탭 1)은 `카드사 × 플랫폼` 매트릭스(실수령 만원)와 대표 카드 조건표로 나뉜다.
`실수령 = 주요(기본) 캐시백 − 연회비`로 계산하고, `최대 혜택`은 별도로 설명만 한다.

## 9개 유형 분류 기준

| # | 유형(slug) | 분류 기준 | 연결 |
| --- | --- | --- | --- |
| 1 | 마일리지 적립 `mileage` | 대한항공(스카이패스) 적립 카드 중심. 아시아나는 통합 절차로 제외 | `/air/`, `/cal/miles/` |
| 2 | 브랜드 호텔·호캉스 `hotel` | 아코르(ALL)·메리어트·힐튼 제휴, 숙박권·엘리트 등급 | `/hotel/` |
| 3 | 여행 · 해외결제 · 해외직구 `travel` | 해외 이용 수수료 면제·해외 적립·환전 우대. 공항 라운지는 유형이 아니라 카드별 배지 | `/air/`, `/hotel/` |
| 4 | 주유·자동차 `fuel` | 리터당 할인, 정비·세차·주차, 차량유지비 적립 | — |
| 5 | 쇼핑·백화점·마트 `shopping` | 온라인몰·백화점·대형마트·쿠팡 특화 | — |
| 6 | 무조건·간편결제 `simple` | 전월실적 조건 없는 적립/할인 + 네이버페이·카카오페이 특화 | — |
| 7 | 대중교통·카페·편의점·구독료 `transit` | K-패스, 스타벅스, 편의점, OTT·정기구독 | — |
| 8 | 프리미엄 `premium` | 연회비 50만원 이상 실제 발급 중인 카드 | — |
| 9 | 통신비·아파트관리비·공과금 `utility` | 자동납부 할인 + **할인 대상과 전월실적 인정은 별개**임을 명시 | — |

각 유형은 TOP 5만 노출하며, 신규 발급이 종료된 카드는 넣지 않는다(카드고릴라 `is_discon` 확인).

## 갱신 규칙

- 기준일을 화면 상단(`최종 확인 …`)과 `sitemap.xml`의 `static_lastmod`에 함께 반영한다.
- 매월 5일 10:00 `scheduled-actions/💳-이달의-카드지도-월간-갱신/action.md`가 4개 플랫폼 실사 → TOP 5 순위·단종 여부 점검 → 배포한다.
- 최대 혜택은 광고성 숫자이므로 기본 혜택(실수령)을 먼저 쓰고, 추가 조건은 별도 문장으로 적는다.
- 확인할 수 없는 수치는 추측해 채우지 않고 "카드사 공식 페이지 확인"으로 남긴다.
